# YZYARCHIVE

> *"I am Warhol. I am the No. 1 most impactful artist of our generation."* — Kanye West

**Live:** https://yzyarchive-two.vercel.app/

Audio and artwork sourced from [YZY Radio](https://yzyradio.com) by Stratosphero. Non-commercial.

## Stack

Next.js 15 · TypeScript · Tailwind CSS v4 · Embla Carousel · shadcn/ui

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play / Pause |
| `N` | Next track |
| `P` | Previous track |
| `← →` | Navigate carousel |
| `Esc` | Close track panel |
