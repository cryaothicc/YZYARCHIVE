## Overview

YZYARCHIVE is a non-commercial web app for exploring Ye's catalog through a clean, artwork-first interface. Browse releases in a carousel, play tracks in the browser, and enjoy the visuals.

## Tech Stack

| Layer      | Tools                         |
| ---------- | ----------------------------- |
| Framework  | Next.js, TypeScript           |
| Styling    | Tailwind CSS, shadcn/ui       |
| UI         | Embla Carousel                |
| Hosting    | Vercel                        |

## Getting Started

```bash
# Clone the repository
git clone https://github.com/<your-username>/yzyarchive.git
cd yzyarchive

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
